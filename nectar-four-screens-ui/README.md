# Nectar Four Screens UI

Bản web React + Vite bám theo thiết kế **Online Groceries App UI** trên Figma Community và 4 ảnh giao diện người dùng đã cung cấp.  
- Home Screen  
- Product Detail  
- Explore  
- Beverages  

## Tính năng đã làm
- Bottom navigation cố định ở cuối trang khi cuộn trên Home / Explore / Beverages.
- Nhấn thẻ **Red Apple** hoặc nút cộng ở Home Screen -> Product Detail.
- Product Detail có tăng / giảm số lượng (`+` và `-`).
- Nhấn **Add To Basket** -> Explore.
- Nhấn **Beverages** ở Explore -> Beverages.
- Có hiệu ứng chuyển màn hình.
- Đã trích xuất toàn bộ ảnh từ **Icon.docx** vào `public/assets/icons_docx` để giữ tài nguyên thiết kế cùng bộ icon người dùng cung cấp.

## Chạy bằng npm trên Visual Studio / VS Code
```bash
npm install
npm run dev
```
Sau đó mở địa chỉ localhost Vite hiện ra (thường là `http://localhost:5173`).
